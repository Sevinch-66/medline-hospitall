# MedLine — Дәрігерге жазылу жүйесі 

## Жоба туралы

MedLine — медициналық орталыққа арналған веб-сайт. Жобаның мақсаты — пациенттерге қажетті дәрігерді табуға және қабылдауға жазылуға көмектесу.

### Жобаның мүмкіндіктері
- Дәрігерлер туралы ақпаратты көру
- Дәрігерлерді аты және мамандығы бойынша іздеу
- Дәрігерлерді сұрыптау
- Қабылдауға жазылу
- Жеке кабинет арқылы жазылуларды қарау
- Қазақ және орыс тілдерін таңдау
- Жасыл-ақ түсті заманауи дизайн

##  1. ZIP архивін ашу

1. `MedLine_GitHub_Project.zip` файлын компьютерге жүктеп алыңыз.
2. Жүктелген ZIP файлын тауып алыңыз.
3. Файлдың үстінен оң жақ батырманы басыңыз.
4. **Extract All / Барлығын шығарып алу** таңдаңыз.
5. **Extract** батырмасын басыңыз.
6. Шыққан папканы ашыңыз.

##2. Сайтты іске қосу

1. Жоба папкасынан `index.html` файлын табыңыз.
2. Файлды екі рет басыңыз.
3. Сайт Google Chrome браузерінде ашылады.

## 3. GitHub-қа жүктеу

1. [GitHub](https://github.com/) сайтына кіріңіз.
2. Жаңа репозиторий құрыңыз.
3. Репозиторий атауын `medline-hospital` деп қойыңыз.
4. **Add file → Upload files** батырмасын басыңыз.
5. ZIP архивін емес, архивтен шығарылған жобаның ішіндегі файлдарды жүктеңіз.
6. **Commit changes** батырмасын басыңыз.

## 4. GitHub Pages арқылы жариялау

1. Репозиторийдің **Settings** бөліміне кіріңіз.
2. Сол жақ мәзірден **Pages** таңдаңыз.
3. **Build and deployment** бөлімінде `Deploy from a branch` таңдаңыз.
4. Branch ретінде `main` таңдаңыз.
5. Папка ретінде `/(root)` таңдаңыз.
6. **Save** батырмасын басыңыз.
7. Жариялану аяқталғанша бірнеше минут күтіңіз.

Сайттың мекенжайы мына үлгіде болады:

`https://СІЗДІҢ-ЛОГИН.github.io/medline-hospital/`

## Ескерту

`Custom domain` бөлімін жеке доменіңіз болмаса, бос қалдырыңыз.

Егер сайт ашылмаса, `index.html` файлы репозиторийдің негізгі деңгейінде тұрғанын тексеріңіз.

## Қолданылған технологиялар

- HTML — сайт құрылымы
- CSS — дизайн және түстер
- JavaScript — интерактивті функциялар
- GitHub Pages — сайтты интернетте жариялау

##Қорытынды
