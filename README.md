[README.md](https://github.com/user-attachments/files/33665609/README.md)[Uploading READ# MedLine — Дәрігерге жазылу жүйесі

Ірі медициналық орталықтың сайты түрінде жасалған оқу жобасы. Интерфейс қазақ және орыс тілдерінде жұмыс істейді. Медициналық фотосуреттер интернет арқылы жүктеледі, сондықтан фотоларды көрсету үшін интернет қажет.

## Мүмкіндіктер
- 18 дәрігерден тұратын демо-каталог.
- Дәрігерді аты/мамандығы бойынша іздеу.
- Мамандық бойынша сүзгілеу және аты, тәжірибесі, бағасы бойынша сұрыптау.
- Дәрігер туралы ақпаратты ашу.
- Қабылдауға жазылу, жеке кабинеттен қабылдауларды көру және болдырмау.
- Қазақша/орысша тіл ауыстыру.
- Жазылуларды браузердің `localStorage` қоймасында сақтау.
- `database/schema.sql` ішінде MySQL дерекқор схемасы.

## Іске қосу
1. ZIP архивін шығарыңыз.
2. `index.html` файлын Chrome немесе Edge браузерінде ашыңыз.
3. «Дәрігерлер» бөлімінен маман іздеп, «Жазылу» батырмасын басыңыз.
4. Жеке кабинеттен қабылдауларды басқарыңыз.

## Құрылымы
- `index.html` — сайттың беті
- `css/style.css` — дизайн және мобильді бейімдеу
- `js/app.js` — іздеу, сүзгі, сұрыптау, тіл ауыстыру, жазылу және жеке кабинет
- `database/schema.sql` — MySQL кестелері

## Технологиялар
HTML5, CSS3, JavaScript, localStorage, MySQL (дерекқор схемасы).

## Ескерту
Бұл — оқу жобасының демонстрациялық нұсқасы, нақты аурухананың жұмыс істейтін ақпараттық жүйесі емес. Қазір сервер, нақты MySQL байланысы, шынайы аутентификация, SMS және электрондық медициналық жазбалар қосылмаған. Жеке деректер тек осы браузерде сақталады. Нақты іске қосу үшін қауіпсіз сервер және деректерді қорғау қажет.
