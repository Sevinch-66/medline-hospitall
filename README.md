# MedLine — Дәрігерге жазылу жүйесі

## Жоба туралы

**MedLine** — пациенттерге медициналық қызметтер туралы ақпарат алуға, дәрігерлерді іздеуге және қабылдауға жазылуға мүмкіндік беретін веб-сайт.

Жобаның негізгі мақсаты — дәрігерге жазылу процесін жеңілдету және медициналық орталық туралы ақпаратты пайдаланушыларға ыңғайлы түрде ұсыну.

##Сайттың мүмкіндіктері

- **Басты бет:** медициналық орталық туралы негізгі ақпарат.
- **Дәрігерлер бөлімі:** дәрігерлердің аты-жөні, мамандығы, тәжірибесі және басқа мәліметтері.
- **Іздеу және сұрыптау:** дәрігерлерді аты немесе мамандығы бойынша табу және тізімді сұрыптау.
- **Қабылдауға жазылу:** дәрігерді таңдап, қабылдау туралы өтінім қалдыру.
- **Жеке кабинет:** пайдаланушының жазылуларын көру және оларды басқару.
- **Тіл таңдау:** қазақ және орыс тілдеріндегі интерфейс.
- **Заманауи дизайн:** жасыл және ақ түстер үйлесімі, фотосуреттер және экран өлшеміне бейімделетін интерфейс.

##Қолданылған технологиялар

- **HTML5** — веб-беттің құрылымын жасау.
- **CSS3** — сайттың дизайны, түстері, орналасуы және анимациялары.
- **JavaScript** — іздеу, сұрыптау, тіл ауыстыру және жазылуларды басқару.
- **LocalStorage** — браузерде жазылулар туралы деректерді сақтау.
- **MySQL** — болашақта серверлік деректер қорын ұйымдастыруға арналған SQL құрылымы.
- **GitHub Pages** — сайтты интернетте жариялау.

## Дизайн ерекшеліктері

Сайт медициналық орталықтың кәсіби бейнесін көрсету үшін жасыл және ақ түстермен безендірілген. Интерфейс пайдаланушыға түсінікті болатындай ұйымдастырылған және компьютер мен мобильді құрылғыларға бейімделген.

## Жоба құрылымы

- `index.html` — сайттың негізгі беті.
- `css/style.css` — дизайн мен стильдер.
- `js/app.js` — интерактивті функциялар.
- `database/schema.sql` — деректер қорының SQL құрылымы.
- `README.md` — жоба сипаттамасы.

## Жобаның нәтижесі

Нәтижесінде дәрігерлер туралы ақпаратты қарауға, қажетті маманды іздеуге және қабылдауға жазылу әрекетін орындауға арналған медициналық веб-сайт жасалды.

**Ескерту:** бұл — оқу жобасы. Қазіргі нұсқада жазылулар браузердің LocalStorage қоймасында сақталады. SQL файлы дерекқор құрылымын сипаттайды, бірақ нақты серверге қосылмаған.
